## 📥 التحميل والتشغيل (Installation & Setup)

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. التشغيل المباشر:
اضغط مرتين على ملف **`Killer.bat`**، أو شغلها من التيرمنال:
```bash
python killer.py
```

## ⚙️ الاستخدام:
1. حط **التوكن (Bot Token)** أو احفظه داخل `config.json`.
2. حط **آيدي السيرفر (Guild ID)**.
3. اختر **اسم الرومات** (أو اضغط `Enter` للاسم الافتراضي `🩸・k̷i̷l̷l̷e̷r̷`).
4. اختر نوع الرومات (**1** كتابي / **2** صوتي) وحدد العدد.
